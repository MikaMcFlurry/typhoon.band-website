# Demo audio files

Repo fallback for the demo player (`src/data/songs.ts`). The live site plays
the MP3s from Supabase Storage (`audio-demos` bucket, managed in
Admin → Musik); these files are only used when no Supabase row exists.

Current files (song title on the site → file):

```text
Sen Benim          Sen-Benim.mp3
Karanfil           karanfil-demo.mp3
Gece Yine Düştün   gece-yine-dustun-demo.mp3
Farksilin          farksilin-demo.mp3
Çılgın             cilgin-demo.mp3
Bir Tek Sen        bir-tek-sen-demo.mp3
```

Update 2026-11-24: Sen Benim, Karanfil, Gece Yine Düştün, Farksilin and
Çılgın were replaced with the band's current "mit Vocal" exports from the
band's demo folder on Google Drive (file names kept). In that folder they are
called "Sen benim En güzel yenilgimsin", "Karanfil Ektim", "Başka ol sandım",
"Farklısın" and "cilgin". Bir Tek Sen has no newer export there and is
unchanged.

Use the MP3 files as exported. Do not place WAV/AIFF/FLAC/M4A or DAW project
files here.
