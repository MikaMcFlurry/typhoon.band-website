# Anti-slop checklist (from impeccable.style/slop public page)
Design system: only fonts/colors/radii/type sizes defined in DESIGN.md.
Visual: no decorative grid-line bg; no thick border accent on rounded el; no glassmorphism everywhere; no side-tab accent stripe; no hairline border + wide shadow; no repeating-gradient stripes; no extreme radius on cards; no rough SVG illustrations.
Typography: no label/eyebrow above every heading; no tiny UI text; no flat hierarchy; no icon tile above heading; no italic-serif display headline cliché; no badge above headline; no oversized hero headline crowding CTAs; no crushed letter spacing; no overused font (Inter etc.); not single font for everything; no all-caps body.
Color: no radial halo bg; no soft spotlight; no generic AI palette; no neon glow accents in dark mode; no gradient text; no gray text on colored bg; no default cream/beige.
Layout: no tiny numbered section labels (01/02) unless sequence; cards not flush to scroller edge; no text covered by elements; balanced columns; headings closer to their content than to previous section; no hero metric layout; no identical card grids; varied rhythm spacing; no nested cards; line length 65-75ch; no overflow; no clipped menus.
Motion: no pulsing status dots; no blinking cursor; no auto marquee w/o pause; no bounce/elastic; animate transforms/opacity only; images don't move on hover unless meaningful.
Copy: no repeated text; few em-dashes; no generic marketing claims; no forced contrast slogans.
Imagery: no placeholder illustrations; no jagged masks; images not buried under overlays; no broken images.
Quality: no JS errors; content visible if animation fails; enough padding; no text touching edge; no justified text; WCAG AA contrast; no skipped heading levels; line-height ~1.5 body; body >=16px; no wide tracking on body.
